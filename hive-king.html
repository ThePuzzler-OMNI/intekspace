Instrumented apiary · not a consumer toy

Hive King Chamberlain · Guard · Steward · Armorer

Compact host computer + entrance computer vision + ~50 eFoundations (diode-matrix TDTP sensing) + solar/LiFePO4 power + hive I/O (fans, solenoids, load cells, heat). Pro and standard variants share architecture. Designed for Midwest winter worst-case.

System layers

Hive Steward (host)

Compact AI host (BOM: NVIDIA Jetson Orin Nano Super class · ~67 TOPS). Starlink path · entrance CV · motion 360 security · DB for images/video/metrics · Wi‑Fi serve to app.

Hive Gatekeeper (entrance vision)

Camera ~1–2" above entrance floor over glass; ~1" restricted width. Goals: varroa on bee, pollen type/load, bee size / nectar inference, entry-exit counts, hornet / yellowjacket / beetle invaders. Optics path: IMX477 + CS lens / extension ring trials.

Hive Chamberlain (eFoundations + hub)

Up to ~50 eFoundations; each drives large diode matrices (TDTP pulses) with multi power modes (ambient temp → larva-safe → honey/pollen). Local ID, firmware, buffer. Bus: prefer RS‑485 multi-hub over 50× USB; gold-finger plug-in to Comm Hub.

Hive Armorer · Lady · Larderer · Guard

Armorer: solar 300W class + MPPT + 12V LiFePO4 100Ah cold-tolerant.
Lady / Lord / Chaplain: HVAC fans, Peltier, servos, temp sensors.
Larderer: 4× load cells + 24-bit ADC.
Guard / Jailor: wicket / trap doors, varroa vacuum path, NIR/white LED imaging.

Pro vs standard

Standard

  • Fewer eFoundations (partial matrix coverage)
  • Entrance CV + weight + climate core
  • Shared host software; reduced actuator suite
  • Same voltage bus (12V) for parts commonality

Pro

  • Full eFoundation count + dual-side matrices
  • Full actuator + security + varroa path
  • Best-in-class compute / storage when budget allows
  • Broodminder-coop vs best-in-class paths both considered in design brief

Diode matrix (planning note)

BOM uses 1N4148WS SOD-323 class small-signal diodes (~$0.0015) at thousands per eFoundation (example line: 7172 / PCB × 20 boards). Packages under review: SOD-123 / SOD-523 / SOD-323. Specs (Vf, capacitance, thermal) must still be validated against larva-safe low-power modes before production buy.

Never overheat a cell that may contain larvae — power modes are a hard safety requirement.

KiCAD start checklist

Brief starts with KiCAD multi-project structure (one project per PCB). Use this order so power and bus settle first.

  1. 1 Power Conversion PCB — 12V bus, MPPT interface, sense/monitor, connectors to solar/battery/hubs. Define nominal rails (12 / 5 / 3.3).
  2. 2 Comm Hub PCB — ports for eFoundations (RS‑485 or Ethernet evolution), isolation, gold-finger / M12 mating, uplink to Jetson.
  3. 3 eFoundation PCB — MCU module footprint, matrix mux, diode pads, local storage, edge connector. Start with 1-side prototype matrix before full 7k diodes.
  4. 4 Actuator / HVAC I/O board — motors, solenoids, fans, heater, switches, RTD/load-cell front-end (can share with Larderer ADC).
  5. 5 Entrance / Jailor optics fixtures — mechanical + camera mounts after electrical bus is proven.

Open design questions (from brief)

  • Final host: Jetson only vs dual-path Broodminder-coop hardware
  • eFoundation count for Standard vs Pro; matrix size per foundation
  • Bus: RS‑485 vs multi-drop Ethernet after video bandwidth review
  • Diode package + max pulse energy with larva-safe guarantee
  • IP67 connector standard (M12 vs Deutsch) for outdoor Midwest
  • Starlink power budget on cloudy multi-day stretch
