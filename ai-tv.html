Media pipeline

Order of build: base architecture → storage sovereignty → then automation. Not the reverse.

Stage Rule
1 · Capture Phone / DJI Pocket / wearable stream / camera
2 · Ingest NAS as source of truth — not cloud photos as system of record
3 · Working edit Free tools when needed (e.g. CapCut free); grade tools only when grade matters
4 · AI layer Later — local captions / transcripts / light curation on owned base architecture
5 · Publish Host-managed release into Spaces-class room or public panels only

Subscription discipline

While One Mission base architecture is deploying: no new CapCut Pro, Submagic, Captions-app, or cloud caption SaaS. Free edit tools only when captions are needed this week. Captions and transcripts are a future base capability (local Whisper-class or on-prem) — not a rented monthly feature.

Automation belongs in the owned spine, not scattered vendor lock-ins.
